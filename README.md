# Aalener-Kontaktlinsenrechner
Eine Sammlung von Funktionen zur Berechnung, Visualisierung und Bewertung kontaktlinsenspezifischer Daten. Fokus auf formstabile Linsen und praxisnahe Unterstützung bei optometrischen Entscheidungen.

# Tools zur Anpassung formstabiler Kontaktlinsen

Dieses Repository enthält einen modular aufgebauten Rechner zur Unterstützung bei der Anpassung formstabiler (RGP) Kontaktlinsen. Die Tools richten sich an Kontaktlinsenspezialistinnen, Optometristinnen und Studierende, die mit topographischen Daten, Fluobildern und Linsenparametern arbeiten.

Enthaltene Module:

    Anpassempfehlung – Algorithmus zur Ableitung eines Startlinsenparameters basierend auf Hornhautradien und klinischen Kriterien.
    
    Fluobild‑Beispiele – Referenzbilder typischer Fluoreszein‑Muster zur Interpretation der Passform.
    
    Radienwechsel‑Rechner – Berechnung der resultierenden sagittalen Tiefe bei Änderung des Linsenradius.
    
    HSA‑Umrechner – Umrechnung der Hornhaut‑Scheitelabstände zur korrekten Übertragung von Brillen‑ zu Kontaktlinsenwerten.
    
    Schiefer Zylinder / Gesamtwirkung – Rechner zur Bestimmung der effektiven Gesamtwirkung bei nicht koaxialen Zylinderachsen.

Ziele:

    Vereinfachung der Erstlinsenwahl
    
    Unterstützung bei der Interpretation von Fluobildern
    
    Schnelle Umrechnungen für klinische Entscheidungen

Technik:  

    Der Rechner ist modular aufgebaut, leicht erweiterbar und kann sowohl lokal als auch in Web‑Umgebungen eingebunden werden.
